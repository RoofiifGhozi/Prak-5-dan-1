# Praktikum Android

Repositori ini berisi proyek Prak 1 dan Prak 5.

## Prak 5

Aplikasi Jetpack Compose dengan gambar acak dari internet, resource fallback `outline_10mp_24`, dan teks hasil `100 / 5` (`20`). Activity yang dijalankan adalah `ActivityUtama`. Konfigurasi SDK: minimum 26, compile 36, target 36.

## Prak 1

Proyek navigasi mahasiswa ada di folder `Prak-1`. Halamannya terdiri dari Beranda, Detail, Profil, dan Tentang. Detail menerima ID mahasiswa sebagai argumen navigasi.

## Menjalankan

Buka folder utama repo di Android Studio untuk Prak 5. Untuk Prak 1, buka folder `Prak-1` sebagai proyek tersendiri. Setelah Gradle Sync, pilih emulator/perangkat dan klik **Run** pada konfigurasi `app`.
