# Prak 1 — Navigasi Mahasiswa

Aplikasi latihan navigasi halaman memakai Kotlin, Jetpack Compose, dan Navigation Compose.

## Halaman

- Beranda membuka Detail dengan argumen ID mahasiswa.
- Profil menampilkan data mahasiswa.
- Tentang menampilkan ringkasan aplikasi.
- Tombol Kembali memakai back stack navigasi.

## Menjalankan

Buka folder `Prak-1` di Android Studio, tunggu Gradle Sync, pilih emulator, lalu klik Run pada konfigurasi `app`.
